### 4.2 POMDP 升级: T(s'|s,a) + R(s,a)

```python
class POMDPPolicy:
    """POMDP 完整 (v0.88.0-c, 依赖型 T+R)."""

    def __init__(self, n_arms=10, n_states=4, seed=None):
        ...
        # v0.88.0-c: T[s'|s, a] (n_states x n_states x n_arms)
        # 简化: T[s'|s, a] = base_T + action_perturbation
        # base_T: 强 self-loop (0.7) + 弱跨 (0.1)  (v0.87.0-c 同)
        # action_perturbation[a]: 选该 action 时增加跨状态概率 (+0.1 cross)
        self.transition = np.zeros((n_states, n_states, n_arms))
        for a in range(n_arms):
            base = np.eye(n_states) * 0.7 + np.ones((n_states, n_states)) * 0.1
            # 选该 action 时, +0.1 跨状态概率
            perturbation = np.ones((n_states, n_states)) * 0.1
            np.fill_diagonal(perturbation, 0.0)  # 跨状态 only
            self.transition[:, :, a] = base + perturbation
            # 归一化 row sum = 1
            self.transition[:, :, a] /= self.transition[:, :, a].sum(axis=1, keepdims=True)

        # v0.88.0-c: R(s, a) 固定 (shape n_states x n_arms, 跟 v0.87.0-c random init 兼容)
        # 替换 v0.87.0-c random init → 固定 init (可重现)
        self.reward = self._init_reward_matrix(seed)

    def _init_reward_matrix(self, seed):
        """v0.88.0-c: 固定 R(s, a) init. 简化: state 0 (Engaged) 偏好 action 0-3,
        state 1 (Frustrated) 偏好 action 4-6, 以此类推."""
        rng = np.random.default_rng(seed)
        R = np.zeros((self.n_states, self.n_arms))
        for s in range(self.n_states):
            start = (s * self.n_arms // self.n_states)
            end = ((s + 1) * self.n_arms // self.n_states)
            R[s, start:end] = rng.uniform(0.5, 1.0, end - start)  # 偏好区间高 reward
            R[s, :start] = rng.uniform(0.0, 0.5, start)
            if end < self.n_arms:
                R[s, end:] = rng.uniform(0.0, 0.5, self.n_arms - end)
        return R

    def bayes_update(self, action: int, observation: int) -> None:
        """v0.88.0-c: Bayes update 考虑 action (T(s'|s, a) 依赖 action)."""
        if not (0 <= int(action) < self.n_arms):
            return
        if not (0 <= int(observation) < self.n_observations):
            return
        # Predict: b_pred[s'] = Σ_s T[s'|s, a] * b(s)
        b_pred = self.transition[:, :, action].T @ self.belief_state
        # Update: b_post[s'] ∝ O[obs|s'] * b_pred[s']
        b_post = self.observation_model[observation] * b_pred
        # Normalize
        norm = b_post.sum()
        if norm > 0:
            self.belief_state = b_post / norm
        else:
            self.belief_state = np.ones(self.n_states) / self.n_states
        self.total_observations += 1
```

## 6. 5 个设计决策 (Bisen 拍板 2026-08-11)

### 6.1 Multi-Domain 抽象边界

**决策**: **Domain 抽到基类** (EducationDomain / ScienceDomain / CareerDomain 3 类) + DomainRegistry singleton.

**为什么不是特征注入式**: 特征注入式 Domain 隔衡弱, 不体现 "Multi-Domain" 语义.

**为什么不是并行 Twin**: 并行 Twin 代码重复多 (4 份), 违反 kernel-first 战略.

### 6.2 POMDP 完整范围

**决策**: **依赖型 T(s'|s,a) + R(s,a) 固定**, point-based solver 推迟 v0.89+.

**为什么不是依赖型 + 参数化 R**: motivation_reward_adjustment 已实现 motivation 影响, POMDP R 参数化 motivation 重复.

**为什么不是依赖型 + point-based solver**: 4 sub-version 资源装不下 3 大块 (T 升级 + R 升级 + solver 实现 + solver 集成), 拆版本更聚焦.

### 6.3 4 sub-commit 切分

**决策**: **Multi(2) → POMDP(2)**, 风险递增, 平衡 2 主轴.

**为什么不是 Multi(3) → POMDP(1)**: Multi-Domain 集中 3 sub-versions, POMDP 只有 1 commit, 失衡.

**为什么不是拆 v0.88 + v0.89**: 2 版本 8 commits 路径长, handoff 复杂.

### 6.4 Domain-agnostic Kernel 模式

**决策**: **Kernel (Domain-agnostic 1 套) + Extension (Domain-specific N 套)**.

**为什么**: kernel-first 战略核心 — Kernel 不变, Domain 加 1 个类即可.

### 6.5 BeliefState 保留 (不重命名)

**决策**: **BeliefState 保留, 加 `domain_extension: Dict[str, Any]` 字段**.

**为什么**: 重命名为 `StudentTwin` v0.71.0 推迟, 渐进迁移, 避免大破坏.
