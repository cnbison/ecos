## 三问拍板 (Bisen 2026-08-17)

### Q1 三问默认呈现形态 → **学习首页三卡**

登录后默认"今天学什么"首页, 三张卡 = 三问:
- **我在哪**: 一句通俗化总评 (interpretation.overall) + 关键数 (θ 强弱 / Bloom 主导 / 置信)
- **我的成长**: mini 5D + Bloom 阶梯 (L1→L6 主导层高亮)
- **下一步学什么**: 1-3 条可操作建议 (interpretation.next_steps + LCA intervention), 点"开始做题 →"即进答题

答题是操作, 三问是入口。

### Q2 答题界面信息密度 → **做题时收敛**

答题页只保留: 题目 + 一句通俗化状态 + 提交。
- 5D/Bloom 数值**不在**答题时实时刷新 (去掉顶栏 KPI)
- 答完后: 反馈卡 (对错 + partial credit score + 通俗化解读) → 下一题
- 5D/Bloom/证据全部收敛到"我在哪"页

设计理由: 降低做题认知负担, 通俗化优先于原始数字 (呼应方向审查"UI 是 Evidence 呈现面, 但学生端优先可感知价值")。

### Q3 移动端/平板布局策略 → **响应式重排**

- 单套组件树, CSS media queries:
  - 桌面: 卡片 3 列
  - 平板: 2 列
  - 手机: 单列堆叠 + Tab 底栏化 + 顶栏收起
- CodeMirror 触屏: 仍可编辑, 工具栏收起 (不降级 textarea)
- 不搞 UA 检测独立移动路由 / 双组件树
