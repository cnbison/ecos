## 背景

## 核心结论

1. **ECE 0.24 来源查清**：calibrated V3 ECE = 0.2366（lbc003，56 道题重放），是 v0.74.0 P0-k 冷启动 fallback 后的双 Agent experiment ECE。单 Agent baseline = 0.1740。阈值 0.10，差 0.14（双 Agent 离阈值），差 0.07（已接近单 Agent baseline）。
2. **指标分四层**：CTA 认知层（5D/Bloom/TC/Misconception/LearningDNA/Trajectory/overall_confidence）→ LCA 决策层（LinUCB/Intervention/attribution）→ 双 Agent 互校层（confidence V1/V2/V3 + calibration + calibration_log）→ 验证层（H3/ECE/reliability diagram/显著性检验）。
3. **核心混淆根因**："confidence" 在 ECOS 指 3 个不同东西（V1 增长空间 / V2 系统把握度 / V3 答对概率）。H3 v0.68.0 卡住就是用错了 V1/V2 测答对概率。v0.69.0 B4 改 LinUCB reward=actual_outcome 让 V3=θ@x 变答对概率预测。
4. **版本演进**：v0.69->v0.74 四轮迭代把双 Agent ECE 从 0.76 拉到 0.24（改善 68.4%）：B4 改 reward → v0.70 修路径绕过 → v0.71 修 A 矩阵爆炸 → v0.72 Platt Scaling → v0.73 Isotonic+L2 → v0.74 冷启动 fallback。
5. **关键澄清**：cov = theta_cov（5×5 协方差矩阵，不是 "coverage"）。
6. **卡点诊断**：raw V3（θ@x）系统性低估 0.54（线性模型 + 16 维 + 54 样本拟合不了 0.85 高 baseline），靠后校准补救。短期 fallback 路径已走到尽头，后续候选：跨学生迁移 / 加 difficulty feature / Isotonic 回退 Platt / Plan B 重定义 H3 / P2 State Engine 抽象。
