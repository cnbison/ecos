### 2.3 MotivationProfile 数据结构

```python
@dataclass
class MotivationObservation:
    """单事件 motivation observation (v0.87.0-a)."""
    timestamp: datetime
    signal_type: str  # "frustration" / "engagement" / "confidence" / "trajectory"
    value: float      # [0, 1]
    source: str = "runtime"  # "runtime" / "llm_critic" / "frontend"
    evidence_id: Optional[int] = None


@dataclass
class MotivationProfile:
    """Motivation Profile (v0.87.0-a).

    4 维时序 (跟 5D 平行, 但独立):
      - frustration:  挫败感 [0, 1] (0=无, 1=极端)
      - engagement:   投入度 [0, 1] (0=无, 1=专注)
      - confidence:   信心 [0, 1] (0=无, 1=充分)
      - recent_trajectory: 最近 100 个 observation (deque)
    """
    frustration: float = 0.0
    engagement: float = 0.5
    confidence: float = 0.5
    recent_trajectory: deque = field(default_factory=lambda: deque(maxlen=100))
    evidence_ids: List[int] = field(default_factory=list)

    def add_observation(self, obs: MotivationObservation) -> None:
        """更新对应维度 + 追加 trajectory."""
        # Allowlisted mutation in check_no_direct_state_mutation.py
        if obs.signal_type == "frustration":
            self.frustration = obs.value
        elif obs.signal_type == "engagement":
            self.engagement = obs.value
        elif obs.signal_type == "confidence":
            self.confidence = obs.value
        self.recent_trajectory.append(obs)
        if obs.evidence_id is not None:
            self.evidence_ids.append(obs.evidence_id)
```

### 4.2 POMDP 算法

```python
class POMDPPolicy:
    """小 POMDP solver (v0.87.0-c 雏形).

    4 状态:
      - 0: Engaged   (投入)
      - 1: Frustrated (挫败)
      - 2: Bored     (无聊)
      - 3: Confused  (困惑)

    Belief state: b = P(state) (4-dim 概率向量)
    Transition:    T[s'|s, a] (4x4 per action, 简化: 不依赖 a)
    Observation:   O[o|s'] (4 obs per state, 简化: 简化 observation 函数)
    Reward:        R(s, a) (per state + action)

    算法:
      - select_action: argmax_a Σ_s b(s) * R(s, a)
      - update(observation): Bayes rule b'(s') ∝ O[o|s'] * Σ_s T[s'|s] * b(s)
    """
    N_STATES = 4
    N_ACTIONS = 10  # 跟 LinUCB n_arms 一致

    def __init__(self, n_arms: int = 10, seed: Optional[int] = None):
        self.n_arms = n_arms
        self.belief_state = np.ones(self.N_STATES) / self.N_STATES  # uniform prior
        self.transition = np.eye(self.N_STATES) * 0.7 + np.ones((self.N_STATES, self.N_STATES)) * 0.1
        self.observation_model = np.eye(self.N_STATES) * 0.6 + np.ones((self.N_STATES, self.N_STATES)) * 0.13
        self.reward = np.random.default_rng(seed).uniform(0, 1, (self.N_STATES, self.n_arms))
        ...
```

### 4.3 关键不变量

- **接口同构**: `select_arm(context) -> int` + `update(arm, context, reward)` 跟 LinUCB/Thompson 一致
- **冷启动**: belief_state 初始化 uniform prior (1/4 各)
- **持久化**: dump_state 含 belief_state + transition + observation_model + reward
- **PRNG seed**: 测试用固定 seed (production 走系统 entropy)
- 防御性自检 [8] **仍 hard block** (POMDPPolicy 不 mutate state)
- H3-c4 canary **PASS**

### 4.4 POMDP 雏形限制

- Simplified transition matrix (不依赖 action)
- Simplified observation model (4×4 简单矩阵)
- 不实现 partial observability 的"模型学习" (transition / observation 固定)
- 单 commit 不实现完整 POMDP solver (point-based / SARSOP 等), 留 v0.88+

## 6. 5 个设计决策 (Bisen 拍板 2026-08-11)

### 6.1 4 sub-commit 切分

**决策**: Motivation(2) → POMDP(2), 风险递增, 平衡 2 主轴.

**为什么**: Motivation Profile 改 BeliefState schema (高风险), POMDP 改 Policy 学接口 (低风险). 早做 Motivation 降低 schema 迁移风险.

### 6.2 X 维度迁移策略

**决策**: **保留 X 字段 (向后兼容)**, Motivation Profile 独立新增.

**为什么**: 不破坏 lbc001/lbc002 历史数据, 不让 Intervention / MIRT 等多 producer 路径报错. 渐进迁移, v0.87+ 后续 commit 可考虑移除 X 维度.

### 6.3 POMDP 雏形范围

**决策**: **独立状态观测 + belief inference**, 不实现完整 POMDP solver.

**为什么**: 单 commit 装不下 T(s'|s,a) + R(s,a) + 点基求解. 雏形定义接口 + Bayes update, 后续 v0.88+ 扩展.

### 6.4 Motivation Profile 时序追踪

**决策**: `recent_trajectory` 用 `deque(maxlen=100)` (跟 FeatureExtractor.response_history 同模式).

**为什么**: 100 容量已够近 100 observation 滑动窗口, 跟 FeatureExtractor 统一 in-memory cap.

### 6.5 POMDP 4 状态

**决策**: **Engaged / Frustrated / Bored / Confused** 4 状态.

**为什么**: 4 状态覆盖 K12 教育核心维度. 多于 4 状态增加 model 复杂度, 少于 4 状态覆盖不足.
