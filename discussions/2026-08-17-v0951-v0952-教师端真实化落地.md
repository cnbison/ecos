## 关键设计决策

1. **数据源不 init BeliefEngine**: 班级 roster 为每个学生 init 引擎太重, 教师端全部 DB 直读 students 表 JSON 列 + LCAStore.
2. **证据维度分配复用 Q 矩阵**: `get_question_detail(pid)["a_specialized"]` (≥0.2 加载阈值) 而非重复实现.
3. **干预历史读 LCAStore**: `save_intervention` 无调用点, intervention_history 存 LCA state snapshot.
4. **HashRouter**: Flask 只需托管 `/teacher/` + `/teacher/assets/`, 避免额外 SPA fallback 路由.
5. **POMDP 诊断防御性**: 非 POMDP learner (linucb) → diagnostic=null, UI 兜底提示, 不崩.
6. **check_defensive.sh 前端段**: node_modules 缺失 → fail 提示 npm install (不 silent skip).
