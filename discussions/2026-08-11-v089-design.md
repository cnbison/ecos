## 1. 背景与定位

### 1.1 为什么是 v0.89

- ✅ R(s, a) 固定 init
- ✅ bayes_update(action, observation)

- ❌ 没有 point-based solver (α-vector / PBVI / Perseus / DESPOT)
- ❌ 没有 SARSOP 等完整 POMDP solver

v0.89 范围: 引入 PBVI 雏形, 让 POMDP 真正"belief 精确求解" (Kernel 深化). T/R 学习推迟 v0.90+ (跟 v0.88 design 接力一致).

### 2.2 关键不变量

- **α-vector 是 PBVI 核心数据结构**: 每个 α 对应一个 action, values[n_states] 表示在每个状态上的值
- **PBVI 单步 backup 不学 T / O / R**: 算法本体只做 value iteration, 不动 POMDPPolicy 的 transition / observation_model / reward
- **接口同构 select_arm**: PBVI.best_action(belief) 接口跟 POMDPPolicy.select_arm(context) 一致 (POMDPPolicy 集成留 c)
- **PBVI 纯函数 (无 mutation)**: backup_step / alpha_value / best_action 都是纯函数, 不修改 self.alpha_vectors (新 α-vector 作为返回值)
- **防御性自检 [8] 仍 hard block**: PBVI solver 不 mutate state

### 2.3 PBVI 雏形数据结构

```python
@dataclass(frozen=True)
class AlphaVector:
    """PBVI α-vector (v0.89.0-a).

    每个 α 对应一个 action: α = (action, values[n_states])
    values[s] = 在状态 s 上该 action 的值
    """
    action: int
    values: np.ndarray  # shape (n_states,)

    def __repr__(self) -> str:
        return f"AlphaVector(action={self.action}, values={self.values.tolist()})"


class PBVI:
    """Point-Based Value Iteration 雏形 (v0.89.0-a).

    核心思想:
      - 在一组 belief points B = {b_1, ..., b_K} 上做 value iteration
      - 每个 α 对应一个 action, 表示该 action 在所有 state 上的值
      - backup: 对每个 b ∈ B, 对每个 action a, 算 V_a(b)
        V_a(b) = Σ_s b(s) * R(s, a) + γ * Σ_o P(o|b, a) * max_{α'} α'(b')
      - select_arm(b): argmax_a α_a(b) = argmax_a Σ_s α_a(s) * b(s)

    Attributes:
        belief_points:  评估的 belief 点集合 (List[np.ndarray], shape (n_states,))
        alpha_vectors:  当前迭代的 α-vector 集合 (List[AlphaVector])
        gamma:          折扣因子 (默认 0.95)
        epsilon:        收敛阈值 (默认 1e-4)
        n_iters:        最大迭代次数 (默认 50)
    """

    def __init__(
        self,
        belief_points: List[np.ndarray],
        gamma: float = 0.95,
        epsilon: float = 1e-4,
        n_iters: int = 50,
    ):
        if not belief_points:
            raise ValueError("PBVI: belief_points 不能为空")
        if not (0.0 < gamma <= 1.0):
            raise ValueError(f"PBVI: gamma={gamma} 必须 (0, 1]")
        self.belief_points = belief_points
        self.alpha_vectors: List[AlphaVector] = []  # 初始空, 由 backup 填充
        self.gamma = gamma
        self.epsilon = epsilon
        self.n_iters = n_iters

    def backup_step(
        self,
        transition: np.ndarray,        # shape (n_states, n_states, n_arms) — POMDPPolicy.transition
        observation_model: np.ndarray,  # shape (n_observations, n_states) — POMDPPolicy.observation_model
        reward: np.ndarray,              # shape (n_states, n_arms) — POMDPPolicy.reward
    ) -> List[AlphaVector]:
        """PBVI 单步 backup (v0.89.0-a).

        算法:
          对每个 action a (n_arms):
            对每个 belief point b (K):
              V_a(b) = Σ_s b(s) * R(s, a) + γ * Σ_o P(o|b, a) * max_{α'} α'(b')

        P(o|b, a) 计算 (per Sondik 1971):
          P(o|b, a) = Σ_s' O[o|s'] * Σ_s T[s'|s, a] * b(s)
          b'_a(s') = O[o|s'] * Σ_s T[s'|s, a] * b(s) / P(o|b, a)

        Returns:
            List[AlphaVector]: 每个 action 一个 α (action, values)
        """
        n_arms = reward.shape[1]
        new_alphas: List[AlphaVector] = []

        for a in range(n_arms):
            values = np.zeros(len(self.belief_points))
            for b_idx, b in enumerate(self.belief_points):
                # 即时 reward
                immediate = float(b @ reward[:, a])
                # 未来 expected value
                future = 0.0
                for o in range(observation_model.shape[0]):
                    # P(o|b, a) + next belief b'_a
                    # b'(s') = O[o|s'] * T[:, :, a].T @ b / P(o|b, a)
                    T_a = transition[:, :, a]      # T[s'|s, a]
                    b_next_unnorm = observation_model[o] * (T_a.T @ b)
                    p_obs = b_next_unnorm.sum()
                    if p_obs > 0:
                        b_next = b_next_unnorm / p_obs
                        future += p_obs * self._alpha_value_at(b_next)
                values[b_idx] = immediate + self.gamma * future
            new_alphas.append(AlphaVector(action=a, values=values))
        return new_alphas

    def _alpha_value_at(self, belief: np.ndarray) -> float:
        """在给定 belief 上算 max α(b).

        雏形 (a 阶段): 仅跟当前 alpha_vectors 比较.
        """
        if not self.alpha_vectors:
            return 0.0
        return max(float(α.values @ belief) for α in self.alpha_vectors)

    def alpha_value(self, belief: np.ndarray) -> float:
        """对外 API: 在 belief 上算 max α(b)."""
        return self._alpha_value_at(belief)

    def best_action(self, belief: np.ndarray) -> int:
        """对外 API: argmax_a α_a(b).

        雏形: 返回 belief 上 α 值最大的 action (跟 POMDPPolicy.select_arm 同构).
        """
        if not self.alpha_vectors:
            return 0  # 雏形退化: 无 α 时返 0
        best_a = 0
        best_v = float(self.alpha_vectors[0].values @ belief)
        for α in self.alpha_vectors[1:]:
            v = float(α.values @ belief)
            if v > best_v:
                best_v = v
                best_a = α.action
        return best_a
```

### 2.4 关键决策

- **PBVI 雏形用 belief points 静态集**: 简化 v0.89.0-a, belief point 集由调用方传入 (默认 4 个跟 state 一一对应). 动态 sampling 留 v0.89.0-b.
- **α-vector 不可变 (frozen dataclass)**: 防御性自检 [8] 风格一致 — 避免 solver 内部 mutation 干扰外部.
- **backup_step 是纯函数**: 输入 transition / observation_model / reward, 输出新 α-vectors (不修改 self.alpha_vectors). 真正的 update 走 update_alpha_vectors (b 阶段).

### 3.2 PBVI 算法本体完整化

```python
class PBVI:
    """PBVI 完整算法 (v0.89.0-b)."""

    def update_alpha_vectors(self, new_alphas: List[AlphaVector]) -> bool:
        """更新 α-vector + 收敛检测 (v0.89.0-b).

        Returns:
            bool: 是否收敛 (max change < epsilon)
        """
        if not new_alphas:
            return False
        max_diff = 0.0
        if not self.alpha_vectors:
            self.alpha_vectors = new_alphas
            return False
        for new_α in new_alphas:
            old_α = next((α for α in self.alpha_vectors if α.action == new_α.action), None)
            if old_α is None:
                self.alpha_vectors.append(new_α)
                continue
            diff = float(np.max(np.abs(new_α.values - old_α.values)))
            if diff > max_diff:
                max_diff = diff
        self.alpha_vectors = new_alphas  # 雏形简化: 直接替换
        return max_diff < self.epsilon

    def solve(
        self,
        transition: np.ndarray,
        observation_model: np.ndarray,
        reward: np.ndarray,
    ) -> int:
        """PBVI 主算法: iterative backup + 收敛 (v0.89.0-b).

        Returns:
            int: 实际迭代次数
        """
        last_alphas = self.alpha_vectors
        for i in range(self.n_iters):
            new_alphas = self.backup_step(transition, observation_model, reward)
            converged = self.update_alpha_vectors(new_alphas)
            if converged:
                return i + 1
            last_alphas = new_alphas
        return self.n_iters


def reachable_belief_points(
    transition: np.ndarray,
    observation_model: np.ndarray,
    initial_belief: np.ndarray,
    n_steps: int = 5,
    n_samples_per_step: int = 4,
    seed: Optional[int] = None,
) -> List[np.ndarray]:
    """reachable belief point sampling (v0.89.0-b).

    简化算法:
      - 从 initial_belief 出发
      - 随机采样 (action, observation) 对, 算 next belief
      - 收集 n_steps * n_samples_per_step 个 belief points
      - 加入 initial_belief 作为 anchor
    """
    rng = np.random.default_rng(seed)
    belief_points = [initial_belief.copy()]
    n_arms = transition.shape[2]
    n_observations = observation_model.shape[0]
    current = initial_belief.copy()

    for step in range(n_steps):
        for _ in range(n_samples_per_step):
            a = rng.integers(0, n_arms)
            o = rng.integers(0, n_observations)
            # b'(s') = O[o|s'] * T[:, :, a].T @ b / P(o|b, a)
            b_next_unnorm = observation_model[o] * (transition[:, :, a].T @ current)
            p_obs = b_next_unnorm.sum()
            if p_obs > 0:
                current = b_next_unnorm / p_obs
                belief_points.append(current.copy())
    return belief_points


def uniform_belief_points(
    n_states: int = 4,
    n_samples: int = 10,
    seed: Optional[int] = None,
) -> List[np.ndarray]:
    """uniform simplex sampling (v0.89.0-b).

    用 Dirichlet(1, 1, ..., 1) = uniform on simplex.
    """
    rng = np.random.default_rng(seed)
    return [
        rng.dirichlet(np.ones(n_states))
        for _ in range(n_samples)
    ]
```

### 3.3 关键不变量

- **PBVI.solve 是纯函数 (无 mutation)**: 输入 transition / O / R, 输出迭代次数. self.alpha_vectors 修改是必要 (solver 状态), 但不 mutate 任何 BeliefState.
- **reachable_belief_points 跟 POMDP.bayes_update 一致**: 同一公式 b'(s') = O[o|s'] * T[:, :, a].T @ b / P(o|b, a), 保证 POMDP belief update + PBVI solver 共享同一 belief semantics.
- **uniform_belief_points 是 fallback**: 无 reachable history 时用 uniform simplex sampling.
- **防御性自检 [8] 仍 hard block**

```python
class POMDPPolicy:
    """POMDP solver 集成 PBVI (v0.89.0-c)."""

    def __init__(
        self,
        n_arms: int = 10,
        n_states: int = 4,
        n_observations: int = 4,
        seed: Optional[int] = None,
        use_pbvi: bool = True,
        pbvi_gamma: float = 0.95,
        pbvi_epsilon: float = 1e-4,
        pbvi_n_iters: int = 50,
    ):
        # ... (v0.88.0-c init 不变) ...

        # v0.89.0-c: PBVI solver (可选)
        self.use_pbvi = bool(use_pbvi)
        self.pbvi_gamma = pbvi_gamma
        self.pbvi_epsilon = pbvi_epsilon
        self.pbvi_n_iters = pbvi_n_iters
        self.solver: Optional[PBVI] = None  # 懒加载

    def _init_pbvi_solver(self) -> PBVI:
        """懒加载 PBVI solver (v0.89.0-c)."""
        if self.solver is None:
            # 雏形: reachable_belief_points 从 uniform belief 出发 (production 用 self.belief_state)
            belief_points = reachable_belief_points(
                self.transition,
                self.observation_model,
                self.belief_state,  # current belief
                n_steps=3,
                n_samples_per_step=4,
                seed=None,
            )
            self.solver = PBVI(
                belief_points=belief_points,
                gamma=self.pbvi_gamma,
                epsilon=self.pbvi_epsilon,
                n_iters=self.pbvi_n_iters,
            )
        return self.solver

    def select_arm(self, context: Optional[np.ndarray] = None) -> int:
        """argmax_a: PBVI 路径 (v0.89.0-c) 或 QMDP fallback (v0.88.0-c).

        Returns:
            arm 索引 [0, n_arms)
        """
        if self.n_arms <= 0:
            _log.warning("POMDPPolicy.select_arm: n_arms=%s, 返 0 (degenerate)", self.n_arms)
            return 0
        if self.use_pbvi:
            # v0.89.0-c: PBVI 路径 (lazy init + solve if needed)
            solver = self._init_pbvi_solver()
            if not solver.alpha_vectors:
                # 第一次: 触发 solve
                solver.solve(self.transition, self.observation_model, self.reward)
            return solver.best_action(self.belief_state)
        # v0.88.0-c fallback: QMDP argmax_a b @ R[:, a]
        expected_reward = self.belief_state @ self.reward
        return int(np.argmax(expected_reward))

    def solve_pbvi(self) -> int:
        """显式触发 PBVI solve (v0.89.0-c)."""
        solver = self._init_pbvi_solver()
        return solver.solve(self.transition, self.observation_model, self.reward)
```

### 4.3 关键不变量

## 7. 5 个设计决策 (Bisen 拍板 2026-08-11)

### 7.1 Solver 主轴选 PBVI

**决策**: **PBVI (Point-Based Value Iteration) 雏形**, 不选 POMCP / DESPOT / Perseus / SARSOP.

**为什么不是 POMCP (Monte Carlo Tree Search)**: POMCP 是 online Monte Carlo, 需要大量采样 (10K+). ECOS n_states=4 / n_arms=10 小规模, PBVI 更轻量.

**为什么不是 DESPOT**: DESPOT 是 POMCP 改进, 同样需要大量采样, 而且算法复杂.

**为什么不是 Perseus**: Perseus 是 PBVI 改进 (随机采样替代枚举), 文献清晰但实现复杂. 雏形阶段 PBVI 足够.

**为什么不是 SARSOP**: SARSOP 是 offline + bounded approximation, 实施成本极高. v0.89 范围装不下.

### 7.2 POMDP 完整范围限定 PBVI 雏形

**决策**: **PBVI 雏形 + α-vector + Runtime 集成**, T/R 学习推迟 v0.90+.

**为什么 T/R 学习不一起做**: T/R 学习需要数据 + 评估, Kernel-first 战略下推到 Kernel 深化后期 (跟 v0.88 design §10 接力一致).

**为什么不是 PBVI 完整 + POMCP 雏形**: 单 Phase 4 sub-commit 装不下 2 大块 (PBVI 完整 + POMCP 雏形).

### 7.3 4 sub-commit 切分 (算法本体 → 集成)

**决策**: **a/b 算法本体 + c/d 集成**, 风险递增.

**为什么不是 a 算法 + b 集成 + c/d POMCP**: POMCP 雏形成本太高 (Monte Carlo + 大量采样).

**为什么不是 a 算法 + b POMDP 集成 + c Runtime + d A/B**: v0.88 节奏是 a/b 算法 → c/d 集成, v0.89 一致.

### 7.4 PBVI 默认开启 (use_pbvi=True)

**决策**: **use_pbvi=True 默认**, 测试 / 老 snapshot 可 opt-out.

**为什么默认开**: PBVI 是更精确求解, 默认开. 测试 opt-out 走 QMDP (向后兼容 v0.88.0-c canary).

**为什么不是默认关 opt-in**: 默认关会让 PBVI 形同虚设, Kernel 深化落空.

### 7.5 schema_version="0.89.0-c" 不兼容老 snapshot

**决策**: **dump_state 加 schema_version="0.89.0-c", 老 snapshot raise ValueError**, 跟 v0.88.0-c 一致.

**为什么不兼容**: solver_state 是新字段, schema 不兼容是必然.

**为什么不让 load_state 静默 fallback**: 防御性自检 [5] 强制, 静默 fallback 会污染 POMDP belief_state.

## 8. 风险与不触发条件

### 8.1 触发条件 (满足任一即可启动 v0.89)

- ✅ v0.88.0 完成 (Phase 7+ 抽象推演 #1) - 已满足

- ✅ v0.88.0 POMDP 依赖型 T+R 落地 (c/d) - v0.89 PBVI 在依赖型 T+R 之上深化

### 8.2 不触发条件 (避免 v0.89 推迟)

- ❌ H3 验证失败: 无关 (v0.78 已通过)
- ❌ 现有架构不能稳定支持 PBVI: PBVI 是 POMDPPolicy 子组件, 现有架构兼容
- ❌ PBVI 实施成本超 4 sub-commit 范围: 单 Phase 严格限定 PBVI 雏形 + Runtime 集成, T/R 学习推迟

### 8.3 风险点

| 风险 | 缓解 |
|---|---|
| PBVI 算法本体实施成本高 (backup_step O(n_actions * K * n_observations * n_states)) | ECOS 规模小 (n_actions=10, K=10, n_observations=4, n_states=4 = 1600 ops), 完全可行 |
| reachable_belief_points 采样偏差 | 混合 uniform + reachable: 4 anchor + 12 reachable = 16 belief points |
| solver 懒加载 + solve 时机 | LCAEngine.select_intervention 显式 solve_pbvi, Runtime plan 触发 |
| dump_state schema_version 不兼容 (POMDPPolicy 老 snapshot) | 防御性自检 [5] + raise ValueError + 老 snapshot 提示迁移 |
| Runtime.plan / plan_* kwargs 透传 pomdp_use_pbvi | 简化: 默认 use_pbvi=True, 不透传 kwargs. 未来 v0.90+ 调 |
| LCAEngine select_intervention 显式 solve_pbvi 慢 | 懒加载 + 增量 solve (首次全 solve, 后续增量 backup) 留 v0.90+ |
| PBVI 收敛不满足 (K=10 belief points 不够) | fallback 到 QMDP + _log.warning, 避免 NaN |
