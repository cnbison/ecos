## 4. 唯一需要警惕的研究级问题

**H3 当前数据下未通过**（B 报告：双 Agent V1 ECE=0.7274，V2 ECE=0.3769，均显著差于单 Agent 0.2366）。

但根因已定位：**不是互校架构失败，是 confidence 指标选错**——
- `expected_gain` 测的是干预效果（LinUCB reward/gain），不是答对概率。
- `overall_confidence` 测的是系统对自身估计的把握度，不是答对概率。

v0.69.0 PRD 已提出 B4+C1+D1 方案修正：让 LinUCB reward = actual_outcome，使 `expected_gain` 自动变成答对概率预测。这属于指标细化，不是方向漂移。
